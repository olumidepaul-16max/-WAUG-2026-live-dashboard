# WAUG 2026 — Report & Live Dashboard

A written analysis of the **West African Universities Games 2026** at Obafemi Awolowo
University, Ile-Ife, plus a live dashboard of the same feed.

Built with Streamlit on top of the [AlliSports Data](https://data.allimediahub.com) feed, so
everything on the page updates straight from the official results — no hardcoded numbers.

## What's inside

**Report** — a long read on what produced the medal table: how concentrated the medals were,
whether breadth or conversion won them, where OAU's 63-medal lead came from, how sensitive the
ranking is to the scoring rule, and what the table leaves out.

**Dashboard** — per-sport fixtures, results, group tables (or a derived league table where none
is published) and statistics. Deep links work: `?sport=FBL`.

**Data** — the medal table, all 478 medal rows, the sport pools and every match as CSV, with the
endpoints listed so the figures can be reproduced.

**Team** — who built it and how.

## Covered sports

All 20 sports in the feed: Athletics, Badminton, Basketball, Boxing, Chess, Esports,
Football, Handball, Hockey, Judo, Rugby, Scrabble, Squash, Swimming, Tennis, Taekwondo,
Table tennis, Volleyball, Weightlifting and Wrestling.
